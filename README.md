# GeoProof (набросок)

**Интерактивная математическая среда для геометрических построений и оформления доказательств.**

GeoProof объединяет инструменты двумерного геометрического моделирования и рабочее пространство для построения математических рассуждений. Проект предназначен для изучения евклидовой геометрии, математической логики и принципов строгого доказательства.

Основная идея проекта — разделить геометрическую конфигурацию и математическое доказательство, сохранив возможность работать с ними в рамках одной среды.

---

## Возможности

### Геометрическое моделирование

GeoProof предоставляет инструменты для создания и исследования геометрических конфигураций.

Поддерживаются:

- создание свободных и зависимых точек;
- построение отрезков и треугольников;
- создание окружностей;
- построение середин отрезков;
- определение точек пересечения;
- работа с углами и их величинами;
- построение медиан, высот и биссектрис;
- привязка точек к нескольким геометрическим объектам;
- активные ограничения параллельности и перпендикулярности;
- ограничения равенства длин и углов;
- перемещение связанных геометрических конфигураций;
- управление масштабом и положением рабочей области.

Зависимые объекты пересчитываются при изменении исходных элементов. Это позволяет исследовать геометрическую конфигурацию, наблюдать взаимосвязи между объектами и проверять устойчивость построений при перемещении точек.

### Математические доказательства

Отдельное рабочее пространство предназначено для последовательного оформления доказательств.

Поддерживаются:

- формулировка условия задачи и требуемого заключения;
- добавление математических утверждений;
- выбор оснований доказательства;
- ссылки на предыдущие шаги;
- структурирование логических выводов;
- работа с временными предположениями;
- вложенные поддоказательства;
- доказательство по случаям;
- устранение квантора существования;
- отображение графа зависимостей доказательства;
- пошаговая демонстрация рассуждений;
- копирование и печать доказательства.

### Математическая логика

В доказательном конструкторе реализованы основные логические связки и правила вывода.

Логические связки:

- конъюнкция — \(\land\);
- дизъюнкция — \(\lor\);
- импликация — \(\to\);
- отрицание — \(\neg\);
- противоречие — \(\bot\).

Реализованные правила включают:

- введение и устранение конъюнкции;
- устранение импликации (Modus Ponens);
- введение дизъюнкции;
- доказательство по случаям;
- двойное отрицание;
- введение противоречия;
- введение импликации;
- введение отрицания;
- классическое доказательство от противного (RAA);
- симметричность и транзитивность равенства;
- введение и устранение кванторов всеобщности и существования.

Для временных предположений предусмотрено управление областями действия и проверка условий закрытия поддоказательств.

## Образовательная система

GeoProof включает несколько уровней учебных материалов.

| Раздел | Назначение |
|---|---|
| Встроенная документация | Практическое руководство по интерфейсу и инструментам |
| Подробное руководство | Объяснение геометрической модели, логики и устройства доказательств |
| Учебный курс | Последовательное изучение геометрии и математической логики |

Учебная программа организована в девять модулей:

1. Старт: математический язык.
2. Базовая геометрия и измерения.
3. Логика и первые доказательства.
4. Евклидова геометрия: основные фигуры.
5. Методы строгого доказательства.
6. Подобие и продвинутая планиметрия.
7. Аналитическая геометрия и преобразования.
8. Формальная логика и основы математических теорий.
9. Итоговая самостоятельная работа.

Курс охватывает путь от базовых геометрических понятий до предикатной логики, кванторов, натурального вывода и основ формальных математических систем.

Прогресс изучения сохраняется в локальном хранилище браузера.

## Принцип работы

Важная особенность GeoProof — разграничение геометрической модели и доказательства.

**Геометрическая модель** описывает объекты, их координаты, зависимости и ограничения.

**Доказательство** описывает логическую последовательность переходов от исходных предпосылок к заключению.

Эти части дополняют друг друга, но не заменяют друг друга.

Например, если две стороны треугольника визуально выглядят равными, это не доказывает их равенство. Аналогично, добавление ограничения перпендикулярности изменяет поведение геометрической модели, но не заменяет математического обоснования соответствующего утверждения.

## Техническая информация

Проект реализован с использованием стандартных веб-технологий:

- HTML5;
- CSS3;
- JavaScript;
- SVG;
- KaTeX для отображения математических формул.

В проекте не используются React, Vue, Angular и другие крупные интерфейсные фреймворки.

KaTeX подключается из локальных файлов проекта.

## Запуск

Для работы не требуется устанавливать зависимости через npm или выполнять сборку проекта.

**Способ 1. Открытие файла**

1. Скачайте репозиторий.
2. Распакуйте содержимое.
3. Откройте `index.html` в современном браузере.

**Способ 2. Локальный HTTP-сервер**

Из корневой директории проекта выполните:

```bash
python -m http.server 8000
```

Затем откройте:

```text
http://localhost:8000
```

Для корректной работы относительных путей локальных ресурсов рекомендуется второй способ.

## Сохранение проектов

Геометрические проекты сохраняются в отдельные JSON-файлы формата GeoProof.

Основные операции:

- **Сохранить проект** — экспорт текущего состояния;
- **Открыть проект** — загрузка ранее сохранённого файла;
- **Ctrl + S** — быстрое сохранение;
- **Ctrl + Z** — отмена действия;
- **Ctrl + Y** — повтор действия.

Сохранение проекта и сохранение учебного прогресса являются независимыми механизмами.

Проекты сохраняются на устройстве пользователя. Автоматическая облачная синхронизация не предусмотрена.

## Ограничения проекта

GeoProof находится в развитии и не является универсальной системой автоматического доказательства теорем.

Текущая реализация имеет следующие ограничения:

- отсутствует универсальный решатель произвольных систем геометрических ограничений;
- нет автоматического поиска доказательств;
- не выполняется полноценная автоматическая проверка истинности произвольных геометрических утверждений;
- свободные текстовые формулировки требуют содержательной проверки;
- геометрическая модель ориентирована преимущественно на двумерную евклидову геометрию;
- для углов используется диапазон от 0° до 180°;
- отдельная универсальная модель бесконечных прямых отсутствует.

Проверка структуры доказательства не должна восприниматься как гарантия математической истинности всех его утверждений.

## Цели проекта

Основное направление развития GeoProof — создание целостной образовательной и математической среды, объединяющей:

1. Геометрическое моделирование.
2. Исследование взаимосвязей между объектами.
3. Формулировку математических утверждений.
4. Структурированное построение доказательств.
5. Изучение математической логики.
6. Постепенный переход к формальным методам.

Долгосрочная цель — сделать строгие математические рассуждения более наглядными и доступными для изучения, не подменяя математическое понимание автоматизацией.
